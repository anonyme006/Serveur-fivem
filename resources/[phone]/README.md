# [phone]

Téléphones supportés via `rp_phone_bridge` :

| Ressource | Config |
|-----------|--------|
| NPWD (recette Qbox) | `Config.Phone = 'npwd'` dans `rp_core` + `rp_phone_bridge` |
| LB Phone | `Config.PhoneResource = 'lb-phone'` |
| sd-phone | `Config.PhoneResource = 'sd-phone'` |

Installez le téléphone choisi dans ce dossier, puis alignez la config.
Ne créez pas un téléphone complet ici.
